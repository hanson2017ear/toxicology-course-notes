# 双酚A研究证据索引

这八项原始研究用于回答[双酚A专题](bpa-review.md)的问题。索引记录2026年11月18日复核时能读到的内容，可按编号回查图1和专题正文。

## 口服代谢与睾丸机制

| 编号与原文 | 研究对象和主要发现 | 阅读位置及限度 |
| --- | --- | --- |
| [[1] Thayer等，2015](https://pubmed.ncbi.nlm.nih.gov/26115537/) | 14名成人单次口服标记BPA，结合代谢迅速并主要经尿排出。 | PubMed摘要及图注。给药条件对应成年人口服，未测睾丸剂量。 |
| [[2] Ben Maamar等，2015](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0117226) | 人及大鼠胎睾丸离体培养，睾酮效应随培养条件和物种或品系变化。 | Results人胎睾丸段、图3。无促性腺激素条件下需同时考虑组织保存和浓度实测值。[作者姓名更正](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0128051) |
| [[3] Li等，2009](https://pubmed.ncbi.nlm.nih.gov/19497385/) | 大鼠原代支持细胞、幼龄和成年大鼠，屏障改变受模型和年龄条件影响。 | PubMed摘要及公开图注。ERK变化与屏障改变伴随出现，未据此确定为必要中介。 |
| [[4] Xiao等，2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4017941/) | 三名供者的人支持细胞，F-actin与黏附蛋白定位改变。 | 细胞培养及统计方法、图3。供者包括青少年，培养细胞数不等于供者数。 |

## 精液、精子DNA与生育结局

| 编号与原文 | 研究对象和主要发现 | 阅读位置及限度 |
| --- | --- | --- |
| [[5] Li等，2011](https://stacks.cdc.gov/view/cdc/191759/cdc_191759_DS1.pdf) | 218名有尿和精液资料的工人，部分精液指标与尿BPA呈不利关联。 | PDF第1—2页、补充分析。中位数分组界定的是样本内指标偏低。 |
| [[6] Goldstone等，2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4426021/) | LIFE备孕人群，418名男性；基线尿加重复精液，35项指标未呈现普遍不利关联。 | Methods 2.2、2.4、2.5及表2—3。未校正多重比较，不能用单项反向结果推断保护。 |
| [[7] Li等，2025](https://pubmed.ncbi.nlm.nih.gov/39823870/) | 474名不孕症门诊男性，重复采尿的横断面研究，BPA与部分彗星试验指标相关。 | 只看了原始摘要。重复采尿能把短期暴露量得准一点，但横断面设计还是分不清暴露和损伤哪个在先。 |
| [[8] Zhang等，2026](https://pubmed.ncbi.nlm.nih.gov/41422654/) | 128名辅助生殖男性的前瞻队列，报告孕前尿BPA与受精、活产的不利关联。 | 以原始摘要为限。公开摘要部分置信区间有异常符号，未采用效应量。BPA单物质与BPA和BPF的混合模型分别解读。 |
