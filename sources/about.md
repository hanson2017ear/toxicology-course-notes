# 来源与勘误

## 怎样找回课件原页

笔记整理自一份 316 页的课件照片。比如“第 90 页”是 PDF 文件第 90 页，和投影片右下角的编号可能不同。照片没有连续的上课日期，所以按课件主题分成八章。有些专题只出现在目录里，手上的照片没有拍到。

第 3 页是名单。第 84 和 181 页是空白分隔。拍重、看不清的数字和只有一帧的视频画面，都在看到的地方注明。

## 怎么看笔记里的旧资料

这是经过 AI 辅助识读和整理的学习笔记，思考题的分析供复习用。课件有些诊断阈值、处置和法规是旧的。如果是为了看现行规则，请从下面的勘误开始，再回到发布机构查最新版。
