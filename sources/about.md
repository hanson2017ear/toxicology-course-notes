# 来源与勘误

## 怎样找回课件原页

笔记整理自一份 316 页的课件照片。比如“第 90 页”是 PDF 文件第 90 页，和投影片右下角的编号可能不同。照片没有连续的上课日期，所以按课件主题分成八章。有些专题只出现在目录里，手上的照片没有拍到。

第 3 页是名单，第 84 和 181 页是空白分隔页。遇到重复照片、模糊数字或只拍下一帧的视频，可以先看对应的笔记，再用页码索引查回原处。

## 怎么看笔记里的旧资料

这些学习笔记使用了 AI 辅助识读课堂照片。思考题后附的是复习时的参考分析。有些投影片仍用旧版诊断标准或法规，下方勘误列出了对应页码和发布机构的链接，便于核对版本。
