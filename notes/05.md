# 帝国灭亡与铅毒理

老师从古罗马人的酒杯和水管讲起。杯子和管道里的铅能提供接触线索。要估计一个人吸收了多少，还得知道铅进入酒水的量，以及这个人喝了多少。

## 古罗马人怎样接触铅

谈到罗马衰亡，老师把铅暴露和气候、瘟疫、宗教、权力、经济等解释放在一起。铅在其中占多大分量，还得找能说明健康和社会影响的证据。

- 古罗马贵族的生育异常引出了 Gilfillan（1965）和 Nriagu（1983）的铅假说。老师举过一组历史估算，贵族、平民、奴隶每日分别摄入 250、35、15 μg 铅。这个推算还要核对所用的方法。
- 铅常伴随银矿开采出现，古希腊、古罗马对铅的使用逐渐增加。老师用公元前 650—350 年拉乌里翁的银、铅开采讲生产如何增加接触机会。
- 当时的含铅器物和生活用品包括餐具、酒杯、化妆品、墙面涂料、陶器和止泻制剂。供水管道有石砌、陶土和铅制等材料。老师用 sapa 和《阿比休斯食谱》讲食物加工中的铅来源。器物会释放多少铅，还要靠检测。
- 讲生殖发育毒性时，老师提到女性可能出现月经失调、流产、早产、死胎，男性精子数目、活动能力和形态也可能改变。铅还可经胎盘或乳汁传到下一代。用这些知识解释宫廷记载时，还需要相应的暴露资料。
- 儿童接触铅可出现神经发育问题，包括智力、注意、阅读和认知困难、多动、眼手协调差和情绪不稳定。老师还列了腹痛、便秘或腹泻、贫血、食欲不振和体格生长迟缓。

老师把古罗马和近代英国并排比较。两边的饮水和餐具都可能带来接触，具体用到铅的地方有所不同。

| 来源类别 | 罗马帝国（公元 1—400 年） | 大英帝国（1700—1960 年） |
|---|---|---|
| 饮水 | 衬铅水渠、铅质蓄水缸 | 铅管、铅质蓄水缸 |
| 餐具 | 铅质器皿 | 铅质器皿、铅釉陶器、铅晶玻璃细颈酒瓶和酒杯 |
| 厨具 | 衬铅蒸煮器皿、铅焊 |  |
| 食物 | 含铅葡萄酒、含铅糖浆（sapa） | 含铅葡萄酒、食品罐头的铅焊 |
| 油漆 | 铅白、铅丹 | 铅白、铅丹、铬黄（铬酸铅） |
| 药品等 | 含铅皮肤药膏、含铅眼线膏等 |  |

## 铅的理化性质、吸收与分布

铅（Pb）是质软、易锻的灰白色重金属，熔点 327℃。讲到烟尘时，老师举了 400—500℃ 加热的例子，铅蒸气逸出后经过冷却、氧化和凝集，形成可吸入的铅烟。课堂还列了 PbO、Pb₃O₄、醋酸铅、碱式碳酸铅、铬酸铅、硝酸铅和硅酸铅。部分氧化物的名称与化学式对照不一致，读到这里先记下温度和氧化条件会影响产物。

| 铅进入人体后 | 课堂举例 |
|---|---|
| 吸收 | 职业情境以呼吸道吸入蒸气、烟尘、粉尘为主，课件列吸收约40%；消化道来自作业场所污染的进食、饮水，列5%—10%，空腹可升高。百分数为课件概括，受铅形态、粒径和个体条件影响。 |
| 血中分布 | 血中铅大部分与红细胞结合，课件写>90%。 |
| 蓄积 | 相当一部分以难溶磷酸铅形式沉积于骨，另可分布至脑、肝、肾。 |
| 靶系统 | 神经、血液及造血、消化、肾、生殖和心血管等，属于多器官毒物。 |

老师举了 20 世纪初澳大利亚昆士兰儿童铅中毒的例子，还讲过服“偏方”后腹痛难忍的病例。遇到腹绞痛与贫血同时出现时，接触史可以帮助区分铅中毒和其他病因。

## 慢性铅中毒的临床表现

| 系统 | 课堂讲到的表现 |
|---|---|
| 神经 | 课堂列了头痛、恶心呕吐、高热、烦躁、抽搐、嗜睡、精神障碍或昏迷。周围神经感觉损伤可表现为肢端麻木、手套袜套样感觉障碍。运动损伤可表现为伸肌无力、麻痹和“垂腕”“垂足”，合称铅麻痹。 |
| 消化 | 口中金属味、食欲减退、恶心、腹痛、腹胀、腹泻与便秘交替。口腔卫生差者的牙龈边缘可见蓝黑色铅线。 |
| 血液 | 点彩红细胞、网织红细胞、碱粒红细胞增多，以及低色素、正常细胞型贫血。老师用染色图指出点彩颗粒在红细胞内的位置。 |
| 肾 | 范可尼综合征，列氨基酸尿、糖尿、磷酸盐尿；少数严重者有蛋白尿、管型尿及肾功能损害。 |

讲儿童易感时，老师用了日本武士后代和含铅增白粉的新闻。报道说研究样本里儿童骨骼铅高于成人，并提到学习、行为和智力问题。要知道这些问题有多普遍，要先看研究取了哪些样本。

## 铅的毒作用机制与血红素合成

老师先讲两种作用。铅在细胞内与蛋白质巯基及细胞器结合，干扰多种酶，也会影响钙、锌、铁等二价离子的功能。

讲血红素合成时，老师用示意图串起线粒体和胞浆之间的反应。甘氨酸与琥珀酰辅酶 A 先生成 ALA，经 ALA 脱水酶（ALAD）进入卟啉合成过程。最后，原卟啉 IX 与 Fe²⁺ 在血红素合成酶（亚铁螯合酶）作用下生成血红素，再和珠蛋白组成血红蛋白。“Pb（－）”标的是受铅抑制的环节。血或尿 ALA、游离原卟啉（FEP）、锌原卟啉（ZPP）可以反映中间产物的变化。

老师把贫血的原因分成“生成少”和“破坏多”。酶受干扰会影响合成。细胞膜 ATP 酶受抑制、钾离子丢失、细胞膜变脆，可缩短红细胞寿命并促进溶血。骨髓幼稚红细胞的超微结构和成熟异常，也与点彩细胞增多有关。

腹绞痛与肠壁的碱性磷酸酶和 ATP 酶受抑制有关，可出现平滑肌痉挛和缺血。肾小管的线粒体、ATP 酶和主动转运受损，则会影响近曲小管细胞的重吸收功能。

## 铅暴露机会与案例

老师先讲铅矿开采、冶炼和含铅合金的熔炼，再讲耐腐蚀设备、管道、罐头构件、印刷、玻璃、搪瓷、油漆、子弹和蓄电池等行业的接触机会。生活中的例子有交通、颜料、涂料、家具、壁纸、文具和玩具。含铅汽油是历史例子，具体产品的铅含量还要看材料和检测。

讲食品加工和包装时，老师举了粉碎设备的涂漆、餐具和焊接罐头。两组婴儿罐头的铅含量分别为非焊接罐头 2.59 μg/kg、焊接罐头 87.1 μg/kg。数据没有交代罐头数量和检测条件。

非职业接触从劣质化妆品讲到贵屿电子垃圾拆解。旧电器堆积、露天拆解，污染可能同时影响工人、家庭和周边居民。老师转述了当地儿童的血铅、铬、镉和部分不良妊娠结局调查。新闻里的“最高”和“都中毒”需要放回调查样本中读。课堂还按时间讲了 2017 年提出停止接收“洋垃圾”、2018 年禁令生效、2019 年马来西亚查获事件。

## 诊断、旧分级与预防

讲铅中毒诊断时，老师把接触史、神经／消化／造血系统表现、实验室检查和现场职业卫生调查放在一起。排除其他疾病也很重要。

老师用旧职业诊断标准举例。血铅 ≥2.9 μmol/L（600 μg/L）或尿铅 ≥0.58 μmol/L（120 μg/L），还要结合尿 ALA、红细胞 ZPP 或相应症状等条件。旧标准也列过络合剂驱排后的尿铅条件。这个例子的重点是用暴露指标、效应指标、临床和现场资料一起判断。

讲处理时，老师提到脱离暴露、对症支持和驱铅治疗，也带到旧资料中的催吐。疑似中毒由医疗人员评估处理。陕西凤翔儿童血铅超标的报道，让人看到污染怎样波及生产场所以外的儿童。

老师讲过五档儿童血铅旧分级，单位是 μg/L。各档为小于 100、100—199、200—450、450—700 及大于等于 700，并配有随访、教育和治疗条目。旧表把低于 100 写作“相对安全”。CDC 另有说明，儿童尚无已知的安全血铅水平，血铅参考值用于人群识别和随访。[CDC 说明](https://www.cdc.gov/lead-prevention/testing/index.html)

讲职业预防时，老师提到替代、机械化与自动化、控制熔铅温度、工艺改革、个人防护和健康监测。弗林特铅水危机是饮水系统和基础设施造成暴露的例子。老师也用餐具、食品、化妆品和文具带大家回顾生活里可能的来源。

## 复习与图解回看

1. 铅为何同时影响神经、消化、造血和肾脏？把各系统的表现与对应的作用机制连起来。
2. 铅线、点彩红细胞、血铅和ZPP分别属于哪一层证据？为什么不能只凭其中一项确定诊断？
3. 职业工人、周边居民和儿童可能通过哪些途径接触同一污染物？
4. 为什么旧儿童分级中的“相对安全”不能直接移作今天的风险结论？注意μg/L与μg/dL相差10倍。
