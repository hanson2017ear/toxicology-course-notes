# 毒理学基本概念

一杯水和短时间内喝下的大量水，对身体的影响可以很不一样。“喝了多少”和“用了多久”，都是描述这次暴露时要记下的事。

这节课讲怎么认识毒物、比较毒性，也讲毒效应在什么条件下出现。

## 1. 为什么水、维生素和食盐也会出现在“毒物”讨论中

老师把氰化钾、维生素 C、水、可口可乐、食盐和砒霜列在同一道题里，让人从中选出“毒物”。题目只给了名称，摄入量和接触方式都留空了。

- **可乐和咖啡因。** 老师借一则过量饮用可乐的新闻，讲咖啡因摄入过多时可能出现心跳加速、失眠、头晕和消化不良。新闻个案的死因要靠实际摄入量和诊断资料来判断。
- **维生素 C。** 老师一边按年龄、孕期和哺乳期讲日常摄入量，一边用旧版维生素 C 片说明书举例，讲大量、长期服用也可能有不良反应。
- **食盐。** 摄入过多时，老师讲到了水钠潴留、血管紧张素–醛固酮系统及盐敏感性高血压。讲到摄入过少时，提到了低钠血症、头晕和乏力。课上以《中国居民膳食指南（2022）》为例，健康成人每日食盐不超过 5 g。
- **饮水。** 从“每天喝八杯水”这个说法讲起，课上举的成年男性和女性每日饮水量分别约为 1700 mL 和 1500 mL。实际需要量会随气温、运动和身体状况而变。

课上列的维生素 C 膳食摄入量分年龄看。0 岁 40 mg/d、半岁 50 mg/d、1 岁 60 mg/d、4 岁以上 70 mg/d、7 岁以上 80 mg/d、11 岁以上 90 mg/d、18 岁以上 100 mg/d。孕早期是 100 mg/d，孕中晚期和哺乳期是 130 mg/d。

老师还拿十种蔬果的维生素 C 含量做比较。红椒和黄椒各取 80 g，橘子取 130 g，比数字时要把份量一起看。樱桃一行列的是 50 g 含 500 mg，没有说明品种、产地和检测条件。这个数别直接套到平时买的樱桃上。

| 食物 | 示例份量 | 维生素 C 示例含量 |
|---|---|---:|
| 樱桃 | 50 g，约 12 粒 | 500 mg |
| 番石榴 | 80 g，约 1 个 | 216 mg |
| 红椒 | 80 g，约 1/3 个 | 136 mg |
| 黄椒 | 80 g，约 1/3 个 | 120 mg |
| 柿子 | 150 g，约 1 个 | 105 mg |
| 青花菜 | 60 g，约 1/4 株 | 96 mg |
| 草莓 | 100 g，约 6 粒 | 80 mg |
| 橘子 | 130 g，约 1 个 | 78 mg |
| 芥蓝 | 60 g，约 1/3 株 | 72 mg |
| 猕猴桃 | 100 g，约 1 个 | 68 mg |

这一组例子带出帕拉塞尔苏斯关于剂量的观点。同一种物质，剂量变了，效应也可能改变。具体到某个人，还要看暴露途径、接触时间和身体状况。

## 2. 毒物、外源化学物及分类

老师讲的毒物，是在一定条件下以较小剂量进入机体，就能干扰正常生化过程或生理功能的物质。它可引起暂时或永久的损害，甚至危及生命。“毒物”也是法规管理中的用语，日常说法、毒理学描述和法律分类各有各的用法。

外源化学物（xenobiotics）存在于外界环境，人可能接触它。进入机体后，它可产生生物学作用。区分外源和内源化学物，先看物质来自机体外部还是内部。

按用途和分布范围，老师列了九类毒物，包括工业毒物、食品中有毒成分、日用化学品、农用化学物、医用药物、环境污染物、生物性毒物、军事毒物和放射性物质。

换成按作用机理分，会得到另一组分类。

| 类别 | 作用与例子 |
|---|---|
| 腐蚀毒 | 有强烈腐蚀作用，例如硫酸、盐酸及强碱 |
| 实质毒 | 可引起脏器病变和损害，例如砷、铅、汞等金属盐与无机磷 |
| 酶系毒 | 抑制正常生命活动所需的酶系，例如有机磷化合物 |
| 血液毒 | 引起血液变化，例如 CO、亚硝酸盐 |

同一种物质可以同时按用途和作用机理归类。

## 3. 毒性怎样比较

毒性（toxicity）指化学物质引起生物体有害作用的能力。讲到化学结构与生物活性的联系，老师用沙利度胺对映体和苯胺、硝基苯作例子。沙利度胺的两种对映体在生理 pH 下可快速相互转化，判断人体里的作用要把这种变化算进去。

在同样的实验条件下，造成的损害越强，毒性越大。若比较的是同一种损害，所需剂量越小，通常说明毒性越大。

半数致死剂量（median lethal dose，LD₅₀）是引起半数受试对象死亡所需的剂量，课上用 mg/kg 表示。这个指标用于比较急性致死毒性，也可用于急性毒性分级。慢性毒性、致癌性和生殖毒性各有自己的评价指标。

下面是老师举的 LD₅₀ 数值。要比较两个数，先确认受试物种、暴露途径和观察期相同，再核对数据出处。

| 化学物 | 示例 LD₅₀（mg/kg） | 化学物 | 示例 LD₅₀（mg/kg） |
|---|---:|---|---:|
| 糖 | 29,700 | 咖啡因 | 130 |
| 乙醇 | 14,000 | DDT | 100 |
| 醋 | 3,310 | 砷 | 48 |
| 食盐 | 3,000 | 对硫磷 | 3.6 |
| 阿特拉津 | 1,870 | 尼古丁 | 1 |
| 马拉硫磷 | 1,200 | 二噁英 | 0.001 |
| 阿司匹林 | 1,000 | 肉毒杆菌毒素 | 0.00001 |

## 4. 毒性分级、选择性与易感差异

讲急性中毒时，老师用了肉毒素中毒的新闻案例。

课上按 LD₅₀ 讲急性毒性的分级，从极毒、剧毒、中等毒到低毒、微毒和无毒。

讲到特殊毒性时，老师以致畸指数为例。

**致畸指数＝母体LD₅₀／胎仔最小致畸剂量。**

课上所列分档为大于 100“强致畸性”、10–100“具致畸性”、小于 10“无致畸性”。这些标签对应具体试验的剂量和暴露窗口。

毒性还可以从下面几个角度分。

- 一般毒性与特殊毒性；特殊毒性列致畸性、致癌性、致突变性。
- 按剂量和时间划分的急性、亚慢性、慢性，以及短期／长期毒性。
- 选择毒性，即同一化学物对不同物种、组织或细胞的影响不完全一样。

群体内的易感性与年龄、性别、遗传因素、营养状况和病情有关。讲遗传因素时，老师举了先天性葡萄糖-6-磷酸脱氢酶缺乏的例子。同一个人的不同器官也会有不同反应。外源化学物直接发挥毒作用的器官叫靶器官，课上用百草枯与肺损伤说明这一点。

## 5. 毒效应、剂量和暴露途径

毒效应（toxic effect）是化学物对机体造成不良或有害的生物学改变。以一氧化碳中毒为例，老师讲了化学物本身或其代谢产物如何在作用部位达到一定量、停留一定时间，并与组织大分子发生作用。

| 名称 | 含义 |
|---|---|
| 暴露剂量 | 单位体重所暴露的外源化学物数量，或所处环境中的浓度 |
| 给予剂量 | 动物实验中的暴露／给药剂量 |
| 内剂量（吸收剂量） | 穿过皮肤、呼吸道或消化道等吸收屏障后进入体内的量 |
| 靶器官剂量 | 到达发生毒效应的器官或组织的量 |

暴露量一样，实际吸收的量也可能不同。常见接触途径包括胃肠道、呼吸道、皮肤及注射。注射还可分静脉、腹腔、皮下、肌内等途径。进入身体的途径会影响吸收速度和中毒表现。[剂量术语：美国环保署](https://www.epa.gov/expobox/exposure-calculations)

老师用饮酒量和冠心病相对风险讲 U 型、J 型剂量–反应曲线。横轴是饮酒量，纵轴是相对风险，曲线旁标了不确定范围。要判断饮酒是否有保护作用，还得看研究设计和混杂因素。

## 6. 毒性参数与安全限值

老师用剂量–反应曲线区分 NOAEL 和 LOAEL。换了实验条件或观察的指标，这两个值都可能变。

- NOAEL：未观察到有害作用的剂量水平。
- LOAEL：观察到有害作用的最低剂量水平。

接着老师用生活饮用水卫生标准、室内空气质量标准、工作场所有害因素职业接触限值举例，讲毒性资料和卫生标准怎么联系起来。实际查限值时用现行标准。

随堂题请大家在 50 字以内回答「食盐是否是毒物」，答题纸右上角写编号和姓名。食盐适量摄入有生理作用，过量或在特定条件下会造成损害，毒效应取决于剂量和机体状况。
